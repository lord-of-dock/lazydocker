## usage

To display help:

```bash
$ docker run --rm -i sinlov/lazydocker --help
```

use as exec:

```bash
$ sudo curl -L --fail https://raw.githubusercontent.com/lord-of-dock/lazydocker/main/run.sh -o /usr/local/bin/lazydocker
$ sudo chmod +x /usr/local/bin/lazydocker
# then check
$ lazydocker --help
```
